# Spec: Remove document and window from React code V1

Status: draft
Out of scope: `frontend/src/main.tsx` (`document.getElementById('root')` mounts the app), Go, bindings, a DOM helper module that wraps the same globals

Cursor: implement this spec only. Read `frontend/AGENTS.md` and `.cursor/rules/no-dom-globals.mdc` first. After this change, `document` and `window` do not appear under `frontend/src` except `main.tsx`.

## Already done

`OpenWithMenu` no longer listens on `document` or arms `window.setTimeout`. The submenu is `NestedMenuItem` (`frontend/src/shared/ui/NestedMenuItem.tsx`). Do not put the listeners back.

## Rule

A component, hook, or helper does not name `document` or `window`.

- Close, focus, and hover stay on React/MUI props. Nested menus use `NestedMenuItem`.
- A delay that is the product behavior (debounce, flush a search batch) uses the global functions `setTimeout` / `clearTimeout`, never `window.setTimeout`.
- Do not add a timer whose only job is to focus a node or to bridge a portaled menu.
- Do not add `shared/lib/dom.ts` that re-exports `document` / `window`.

## Replace these

Each row is one call site. Behavior stays the same. The replacement column is the whole change for that row.

| File | What it does today | Replacement |
| --- | --- | --- |
| `widgets/toolbar/hooks/useFileOpDialogs.ts` | `window.setTimeout` focuses the delete button 50ms after open | Focus the button with MUI `autoFocus` on the confirm button. No timer. |
| `widgets/file-pane/hooks.ts` | `window.setTimeout` / `clearTimeout` for type-ahead | Global `setTimeout` / `clearTimeout`. |
| `widgets/file-pane/hooks.ts` | `document.activeElement` to see if a field is focused | Track focus with `onFocus` / `onBlur` on the path field and the grid, stored as a boolean. Read that boolean. |
| `widgets/file-pane/hooks.ts` | `window.getSelection()?.removeAllRanges()` | Drop it. Selection clear belongs to the drag layer that already owns the gesture. |
| `widgets/file-pane/hooks.ts` | `window.setTimeout(run, 0)` after a pane action | Call `run` from the event that scheduled it. |
| `widgets/search/hooks/useSearchSession.ts` | `window.setTimeout` batches search hits | Global `setTimeout` / `clearTimeout`. |
| `widgets/search/SearchDialog.tsx` | `window.setTimeout` focuses inputs | `autoFocus` on the field that should take focus when the dialog opens. |
| `widgets/search/SearchDialog.tsx` | `window.confirm` before replace-all | The existing confirm dialog pattern (`Dialog`). No browser confirm. |
| `widgets/toolbar/helpers.ts` | `document.querySelector` clicks the folder-sizes button | Call the sizes handler directly. The button's `onClick` and this helper share one function. |
| `widgets/go-to/GoToDialog.tsx` | `window.setTimeout` debounces the query | Global `setTimeout` / `clearTimeout`. |
| `pages/file-manager/hooks/useFileManagerKeyboard.ts` | `window.addEventListener('keydown')` | `onKeyDown` on the file-manager shell element. The shell is focused or the handler is on the same node that already receives pane keys. |
| `features/transfers/useTransferEvents.ts` | `window.setTimeout` removes a finished job | Global `setTimeout`. |
| `widgets/toolbar/components/NameDialog.tsx` | `window.setTimeout` selects the filename stem | Select the stem in the input's `onFocus`. |
| `pages/file-manager/helpers.ts` | `document.querySelector` finds a pane grid | Pass the grid root ref from the pane into the caller. |
| `widgets/terminal/PaneTerminal.tsx` | `window` mouse listeners and `document.body` cursor while resizing | Resize on the terminal split's own `onMouseDown` / `onMouseMove` / `onMouseUp`. Cursor via `sx` on the split (`cursor: 'row-resize'`), not `document.body.style`. |
| `widgets/file-pane/FileDragLayer.tsx` | `document.body` drag classes and `window.getSelection` | Toggle the drag class on the React root node the app already renders (`#root` via a ref from `App`), or set the class in the drag handler on that element. Clear the selection by not starting a native selection (`userSelect: 'none'` on the row while dragging) instead of `getSelection`. |
| `features/dnd/dragState.ts` | `window` key and mouse listeners for the move modifier | Read `event.altKey` / `event.metaKey` on the drag events the layer already receives. |
| `app/theme.tsx` | `window.matchMedia` for the system theme | `useMediaQuery` from `@mui/material/useMediaQuery` with `prefers-color-scheme`. |
| `features/updates/hooks/useAutoUpdateCheck.ts` | `window.setTimeout` delays the update check | Global `setTimeout` / `clearTimeout`. |
| `shared/ui/ErrorBoundary.tsx` | `window` `error` / `unhandledrejection`, `window.location.reload` | Keep the React error boundary for render errors. For reload, call a prop `onReload` that `main.tsx` provides; `main.tsx` is the only file that may touch `location`. Do not add `window` listeners in the component. |
| `pages/file-manager/hooks/useMouseNavButtons.ts` | `window` `mousedown` / `auxclick` for back/forward buttons | `onMouseDown` / `onAuxClick` on the file-manager shell. |

## Check

`rg -n "\\b(document|window)\\b" frontend/src` prints only `frontend/src/main.tsx`.

Existing Playwright specs still pass, including `e2e/specs/ui-polish.spec.ts` (Open with Escape) and `e2e/specs/bookmarks.spec.ts`. Do not add a test whose only assertion is the absence of the words.

## Must not

- A wrapper module whose implementation is `export const doc = document`.
- `window.setTimeout` left behind as "the same thing".
- Editing `frontend/bindings/**`.

## Done when

The search above matches only the mount in `main.tsx`, and the menus, search, drag, and theme behaviors listed above still work.
