# Spec: Quick places menu next to "new tab" V1

Status: draft
Out of scope: user-configurable/custom places (that's what bookmarks already are — see `BookmarksSelect.tsx`), Templates/Public-share folders, per-OS toggle in settings, remote well-known folders (there's no "Desktop" on an SSH box)

## Goal

Each pane's tab bar (`PaneTabs.tsx`) has one "+" button (`onAddTab`) that opens a new tab at the pane's *current* path. Add a second, small control right next to it: a dropdown listing common local folders — Home, Desktop, Documents, Downloads, Pictures, Music, Videos — filtered to only the ones that actually exist on this machine. Picking one opens a **new tab** at that path (same pane), it does not navigate the current tab.

This mirrors the existing `DrivesMenu` (`frontend/src/widgets/toolbar/components/DrivesMenu.tsx` + `useDrives.ts`) pattern, but per-pane and opening a new tab instead of navigating the active one.

## Why this isn't a bookmarks feature

Bookmarks (`BookmarksSelect.tsx`, SQLite-backed) are user-curated and already exist in the toolbar. Quick places are OS-derived, not stored, not editable, always the same seven-or-fewer entries. Don't merge the two — this is compute-once-per-launch, not a CRUD list.

## Backend

No dependency to add — `github.com/adrg/xdg` is already pulled in transitively (`go mod why github.com/adrg/xdg` → via `wailsapp/wails/v3/pkg/application`), just not imported by our code yet. `go mod tidy` will move it from `// indirect` to a direct `require` once we import it — that's expected, not a new dependency being introduced.

Why `xdg.UserDirs` instead of hardcoding `filepath.Join(home, "Desktop")` etc: it resolves the *actual* OS-known-folder path per platform —

- **Windows**: `paths_windows.go` calls the real Known Folder API (`windows.FOLDERID_Desktop` / `_Downloads` / `_Documents` / `_Music` / `_Pictures` / `_Videos`) via `SHGetKnownFolderPath`, so it's correct even when a user has relocated Documents to another drive or is on a non-English Windows build where the folder name isn't literally "Documents".
- **macOS**: fixed `~/Desktop`, `~/Documents`, `~/Downloads`, `~/Music`, `~/Pictures`, `~/Movies` (note: `Videos` field maps to `Movies` on macOS — already handled inside the library).
- **Linux**: reads `~/.config/user-dirs.dirs` (XDG user-dirs spec) with `~/Desktop` etc as fallback, so it respects a user who renamed/moved these via their DE's settings.

Hardcoding folder names would silently be wrong on Windows (localized/relocated) and ignore Linux XDG customization — that's real correctness, not gold-plating.

New, in `internal/filesystem/filesystem.go` (next to `HomeDir`):

```go
// QuickPlaces returns well-known local folders that exist on this machine,
// in a fixed display order. Best-effort: a folder that doesn't exist or
// can't be statted is silently omitted, never an error.
func QuickPlaces() []domain.QuickPlace {
    home, err := HomeDir()
    if err != nil {
        return nil
    }
    candidates := []domain.QuickPlace{
        {Name: "Home", Path: home},
        {Name: "Desktop", Path: xdg.UserDirs.Desktop},
        {Name: "Documents", Path: xdg.UserDirs.Documents},
        {Name: "Downloads", Path: xdg.UserDirs.Download},
        {Name: "Pictures", Path: xdg.UserDirs.Pictures},
        {Name: "Music", Path: xdg.UserDirs.Music},
        {Name: "Videos", Path: xdg.UserDirs.Videos},
    }
    out := make([]domain.QuickPlace, 0, len(candidates))
    for _, c := range candidates {
        if c.Path == "" {
            continue
        }
        if info, err := os.Stat(c.Path); err == nil && info.IsDir() {
            out = append(out, c)
        }
    }
    return out
}
```

## Frontend

`frontend/src/entities/file/queries.ts` — new hook next to `useHomeDir`:

```ts
export const useQuickPlaces = () =>
  useQuery({
    queryKey: queryKeys.quickPlaces,
    queryFn: () => FileService.GetQuickPlaces() as Promise<QuickPlace[]>,
    staleTime: Infinity, // same rationale as useHomeDir — OS folders don't move mid-session
  });
```

`queryKeys.quickPlaces = ['quickPlaces']` — one shared cache entry, both panes' tab bars read the same query (no per-pane fetch).

`frontend/src/widgets/file-pane/PaneTabs.tsx` — add a small chevron `IconButton` (`ArrowDropDownIcon` or similar) immediately after the existing "New tab" `IconButton`, opening a `Menu` anchored to it (state: local `anchor` in a new colocated hook, same shape as `useDrives`'s `anchor`/`setAnchor`). Menu items: one per `QuickPlace`, icon chosen by `place.name` (Home/Desktop/Documents/Download/Pictures/Music/Videos → matching `@mui/icons-material` icon, same spirit as `DrivesMenu`'s `kindIcon`). Empty list (all seven missing/unreadable, e.g. sandboxed CI container) → don't render the chevron at all, no empty-menu state to design for.

`frontend/src/widgets/file-pane/hooks.ts` — new handler next to `onAddTab`:

```ts
const onAddTabAt = (targetPath: string) => {
  enterPaneTab(id, targetPath);
  addTab(id, targetPath);
};
```

No `Exists` pre-check before opening the tab (unlike `navigate()`, which checks because the user typed an arbitrary path) — `GetQuickPlaces` already only returns folders that existed at fetch time; treat the same way `useHomeDir`'s value is trusted elsewhere in the app. `addTab` already sets `activePane: id` and selects the new tab (`features/pane/paneStore.ts:198`), same as the existing "+" button.

Wire `onAddTabAt` through `FilePane.tsx` → `PaneTabs` the same way `onAddTab` already flows (`hooks.ts:331` → `FilePane.tsx:41` → `PaneTabs` props).

## Must not

- Add a new Go dependency — `adrg/xdg` is already vendored (transitive), just import it and let `go mod tidy` promote it to direct.
- Hardcode `filepath.Join(home, "Desktop")`-style paths — wrong on Windows (relocated/localized) and ignores Linux XDG customization.
- Resolve quick places per-pane or based on the pane's current protocol — always local OS folders, regardless of whether the pane is currently on `ssh://`/`smb://`/`mega://`.
- Make quick places editable/persisted — that's what bookmarks are for.
- Re-check `Exists` on every menu open or on click — one best-effort stat at query time, cached for the session (`staleTime: Infinity`), same trust level as `useHomeDir`.
- Fetch quick places twice (once per pane) — one shared query key.
- Include Templates/PublicShare or any place beyond the seven listed — not asked for, adds menu clutter.
