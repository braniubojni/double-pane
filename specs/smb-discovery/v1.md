# Spec: SMB discovery V1

Status: draft
Out of scope: WS-Discovery as a required path, scanning the local subnet with port 445 probes, mounting the share in the OS, remembering every browsed host as a profile automatically

Cursor: implement this spec only. Read `internal/AGENTS.md` and `frontend/AGENTS.md` first.

## Current behavior

SMB connect is typed: host, user, domain, port (`SMBConnectFields`), then `SMBManager.Connect` and a share list (`domain.SMBShare`, dialog mode `smb_shares`). The OS mounts that Finder or the desktop already made show up in the drives menu via `volumes` (`smbfs` in `internal/volumes/parse.go`) and open as local paths (`ConnectResult.LocalMount`). Nothing browses the LAN for servers that are not mounted.

## Desired

A browse action that lists nearby SMB servers by Bonjour/mDNS service type `_smb._tcp`, then lets the user pick one and continue into the existing SMB password and share dialog.

`ConnectionService.BrowseSMB() ([]domain.SMBPeer, error)`

```go
type SMBPeer struct {
    Name string `json:"name"` // instance name
    Host string `json:"host"` // hostname or address
    Port int    `json:"port"`
}
```

Browse runs at most 3 seconds. Partial results return with a nil error if at least one peer arrived; timeout with zero peers returns an empty list, not an error. A missing mDNS permission or unsupported OS returns an error string the dialog can show.

Implementation: one dependency or the OS tool, not both.

- Prefer a small pure-Go mDNS query if a dependency is already in `go.mod`. It is not today, so adding one mDNS client is acceptable.
- Else macOS `dns-sd -B _smb._tcp` with a timeout. Linux `avahi-browse -rtk _smb._tcp` when present. Windows: if neither is available, return "SMB discovery is not available on this system" and keep typed host entry.

Do not probe 445 across an IP range.

## UX

SMB dialog: button "Browse network" `data-testid="btn-smb-browse"`. Results list in the dialog (`data-testid="smb-peer"`). Choosing a row fills host and port, then the user connects as today (password, then `smb_shares`). Browsing does not call `Connect` and does not write a profile.

Empty list copy: "No SMB servers found." Typed host still works when browse fails.

## Tests

Parser test for a fixture of `dns-sd` or `avahi-browse` output → `SMBPeer` rows (name, host, port). Do not require a live network in CI. Timeout helper returns an empty list when the command produces nothing.

## Must not

- Auto-connect to every peer.
- Replace the share picker. Discovery is hosts; shares stay `SMBShare` after auth.
