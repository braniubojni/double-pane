# Spec: Quick view dialog V1

Status: draft
Out of scope: editing in the dialog, HEIC decode, video playback, remote / archive / trash / vault preview, decrypting a vault to preview it, pdf.js, CGo, a PDF rasterizer, preview of more than one file, a separate OS window, a pane sidebar

Cursor: implement this spec only. Read root `AGENTS.md`, `frontend/AGENTS.md`, `internal/AGENTS.md` first. F4 stays "open the built-in editor". This dialog is not the editor.

## Goal

F3 toggles a read-only preview of the focused file in a modal dialog in the center. Images, UTF-8 text, and PDF. The file grid stays full width behind the dialog. Closing the dialog does not change the selection or the path. Arrow keys do not move the preview while the dialog is open.

## Layout

One MUI `Dialog`, `fullWidth`, `maxWidth="md"`, about 70vh tall. Mounted once from `FileManagerPage` inside the existing `Suspense`, and only while the Zustand flag is open:

```tsx
const QuickViewDialog = lazy(() =>
  import('../../widgets/quick-view/QuickViewDialog').then((m) => ({ default: m.QuickViewDialog })),
);
```

CodeMirror and the language packages load on the first F3, not with the file manager. `Suspense` fallback is `null`. Do not render the dialog while the editor workspace is open.

- Toggle: shortcut id `quickView`, default `F3`. `editFile` stays `F4`, `refresh` stays `F5` (`internal/config/config.go` `DefaultShortcuts` and `ShortcutCatalog`, entry next to `editFile`).
- The focused path is the active pane's focus (`paneStore` `leftFocus` / `rightFocus`), not the multi-selection. Derived during render. The dialog title is the file name.
- `runShortcutAction` handles `quickView` the way it handles `toggleTerminal`: flip the Zustand flag. Do not add it to `FILE_OPS_IDS`.
- While the editor is open, `useFileManagerKeyboard` returns before catalog actions. F3 does nothing in that branch. Closing the editor does not open the dialog.
- F3 is handled before the `isEditableTarget` return, so it still toggles the dialog when focus is inside it (including the read-only CodeMirror).
- Escape and the backdrop close the dialog via MUI `onClose`. The window-level Escape handler does not close quick view and does not clear the selection while the dialog has focus. Dialog closed: Esc keeps clearing the selection.
- Toolbar: one icon button on `ToolbarBar`, `data-testid="btn-quick-view"`, pressed state when open. No new menu.

Empty states, inside the dialog:

- Dialog closed: render nothing.
- No focused path, or the focused row is a directory: "Select a file".
- Remote path (`isRemotePath`: `ssh://`, `smb://`, `mega://`), archive path (`filesystem.IsArchivePath`), or `trash://`: "Preview is only available for local files". Do not download and do not read the archive.
- `.dpenc`, or any path whose parent walk hits `vault.Detect` (same idea as `isInsideAnyVault`): "Preview is not available for vault files". Do not decrypt and do not read the ciphertext.

## What it shows

Classify in Go (`internal/preview` or a small file under `internal/filesystem` — prefer `internal/preview` so the file service stays thin). Extension first, then a sniff of the first 8KB for text vs binary.

| Kind | Rule | UI |
| ---- | ---- | -- |
| image | `.jpg` `.jpeg` `.png` `.gif` `.webp`, file ≤ 20MB | `<img>` from the bytes. Fit inside the panel (`object-fit: contain`). |
| text | not an image or PDF, no NUL in the first 8KB, ≤ 256KB returned | read-only CodeMirror. `languageExtensionForPath` (js, jsx, ts, tsx, json, md, go, css, html, py, rs, c/cpp, sql, yaml, and the rest of that switch). Unknown extensions stay plain text. `EditorView.editable.of(false)`, `EditorState.readOnly.of(true)`, line wrapping, `oneDark` when the MUI theme is dark. No save keymap, no `onChange`, no autocompletion. |
| pdf | `.pdf`, file ≤ 20MB | `<iframe>` whose `src` is a `blob:` URL of type `application/pdf`. The webview's own PDF viewer paints it. |
| none | HEIC/HEIF, video, audio, bigger than the cap, or binary that is not PDF | One line: why (unsupported type, or too large) plus the existing Open action (`SettingsService.OpenInOS` / the pane's open). |

Caps are hard. Over the cap, return `kind: none` and do not put the bytes in the response. Text over 256KB is `none` with "File is too large to preview", not a truncated dump.

PDF: do not add `pdf.js`, mupdf, or CGo. If the darwin webview paints a blank iframe, keep the iframe and the Open button. Do not add a second renderer in this spec. Verify the iframe on darwin before calling it done (see Check).

HEIC is unsupported. `internal/imghash` already skips it. Do not add a HEIC decoder here.

## API

`FileService.ReadPreview(path string) (domain.Preview, error)`

```go
type Preview struct {
    Kind      string `json:"kind"` // image | text | pdf | none
    MIME      string `json:"mime,omitempty"`
    Text      string `json:"text,omitempty"`
    Data      []byte `json:"data,omitempty"` // image or pdf bytes; empty for text and none
    Message   string `json:"message,omitempty"`
}
```

- Local regular files only. Directory, remote, archive, trash, `.dpenc`, and paths inside a folder vault: return `kind: none` and the message from Layout. Do not return an error for "unsupported" — the dialog shows `Message`. Return an error only when a local file should have been readable and was not (permissions). The dialog shows that error.
- Sniff and size check before reading the whole file. Use `os.Stat` then a limited read.
- Image and PDF `Data` is the file bytes, not a re-encode.
- No writes. No temp file.

Regenerate Wails bindings. Do not commit `frontend/bindings/**`.

## Frontend

- Zustand flag `open` only (`features/quick-view/`). The path is the active pane's focus, derived during render. Do not copy it into the store with `useEffect`.
- TanStack Query key `['preview', path]`, `enabled` when the dialog is open, the path is a local non-directory file, and it is not remote, trash, or an archive path (existing helpers: `isRemotePath`, `isTrashPath`, `isLocalArchivePath`). Vault refusal stays in Go so a normal-looking path inside a folder vault still gets a message. `ReadPreview` is a query, not a mutation.
- Blob URL: create it from `Data` for image and pdf. `URL.revokeObjectURL` when the path or kind changes. A `useEffect` whose only job is to revoke the object URL is OK (it is an external handle). Do not use an effect to copy preview data into React state.
- Components under `frontend/src/widgets/quick-view/`. Each file about 100–150 lines. Suggested split: dialog shell, body (switch on kind), read-only CodeMirror text, `styles.ts`. MUI path imports.
- `data-testid`: `dialog-quick-view`, `quick-view-image`, `quick-view-text`, `quick-view-pdf`, `quick-view-message`.

## Tests

`go test` for the classifier and `ReadPreview` (table):

- small png → image, non-empty data, mime `image/png`
- utf-8 txt → text, body matches, data empty
- file with a NUL in the first 8KB → none
- pdf extension → pdf (a tiny file starting with `%PDF-` is enough)
- file larger than the cap → none, and the test's file is not fully slurped (assert via a reader limit, or a file just over the cap with a counting reader if you inject one)
- directory, `ssh://…`, `trash://…`, an archive member path → none, nil error
- `.dpenc` and a file under a folder-vault root → none, nil error, and the file bytes are not in the response
- `.heic` → none

No Playwright pixel check. Optional e2e: toggle `btn-quick-view` and expect `dialog-quick-view` only if a fixture file is already how other specs set the pane. Skip e2e if that harness cannot point at a local png.

## Check

In the running app: F3 opens the dialog in the center and the panes stay full width; a png, a txt, and a pdf each show; a `.ts` or `.md` file is colored and cannot be edited; a folder shows the empty message; Esc and the backdrop close the dialog and leave the focus; F3 again also closes it; F4 still opens the editor and F3 does nothing while the editor is open. Confirm the PDF iframe actually paints on darwin. If it does not, ship the Open button and write that in the PR — do not add a JS PDF library.

## Must not

- Open `EditorWorkspace` from this shortcut.
- A writable CodeMirror (no `onChange`, no save).
- A sidebar panel on the pane.
- Preview remote files by downloading them.
- Decrypt a vault, or read vault ciphertext into `Data` or `Text`.
- Write the previewed file, including "save a copy".
- `useEffect` to sync the focused path into state.

## Done when

F3 toggles a local preview for png, txt, and pdf; unsupported paths show a message; the editor shortcut is unchanged; Go tests above pass.
