# Spec: Quick view panel V1

Status: draft
Out of scope: editing in the panel, CodeMirror, HEIC decode, video playback, remote / archive / trash preview, pdf.js, CGo, a PDF rasterizer, preview of more than one file, a floating window

Cursor: implement this spec only. Read root `AGENTS.md`, `frontend/AGENTS.md`, `internal/AGENTS.md` first. F4 stays "open the built-in editor". This panel is not the editor.

## Goal

F3 toggles a read-only preview of the focused file in the active pane. Images, UTF-8 text, and PDF. The file grid stays visible. Closing the panel does not change the selection or the path.

## Layout

One panel, tied to the active pane. It sits on the trailing edge of that pane (after the grid), about 40% of the pane width, minimum 280px. The grid keeps the remaining width. Switching the active pane moves the panel with it. The inactive pane is unchanged.

- Toggle: shortcut `quickView`, default `F3`. F3 is unused today (`config.DefaultShortcuts` has F4 edit and F5 refresh).
- Esc closes the panel when no dialog, editor, go-to, search, or terminal is taking the key. Follow the guards in `frontend/src/pages/file-manager/hooks/useFileManagerKeyboard.ts`.
- Command palette and the shortcut catalog get the same id (`config.ShortcutCatalog`, `runShortcutAction`).
- Toolbar: one icon button on the existing toolbar, `data-testid="btn-quick-view"`, pressed state when open. No new menu.

Empty states, in the panel, not a dialog:

- Panel closed: render nothing.
- No focused file, or the focused row is a directory: "Select a file".
- Remote path (`ssh://`, `smb://`, `mega://`), archive member, or `trash://`: "Preview is only available for local files". Do not download and do not read the archive.

## What it shows

Classify in Go (`internal/preview` or a small file under `internal/filesystem` — prefer `internal/preview` so the file service stays thin). Extension first, then a sniff of the first 8KB for text vs binary.

| Kind | Rule | UI |
| ---- | ---- | -- |
| image | `.jpg` `.jpeg` `.png` `.gif` `.webp`, file ≤ 20MB | `<img>` from the bytes. Fit inside the panel (`object-fit: contain`). |
| text | not an image or PDF, no NUL in the first 8KB, ≤ 256KB returned | read-only `<pre>`. Not CodeMirror. |
| pdf | `.pdf`, file ≤ 20MB | `<iframe>` whose `src` is a `blob:` URL of type `application/pdf`. The webview's own PDF viewer paints it. |
| none | HEIC/HEIF, video, audio, bigger than the cap, or binary that is not PDF | One line: why (unsupported type, or too large) plus the existing Open action (`SettingsService.OpenInOS` / the pane's open). |

Caps are hard. Over the cap, return `kind: none` and do not put the bytes in the response. Text over 256KB is `none` with "File is too large to preview", not a truncated dump.

PDF: do not add `pdf.js`, mupdf, or CGo. If the darwin webview paints a blank iframe, keep the iframe and the Open button. Do not add a second renderer in this spec. Verify the iframe on darwin before calling it done (see Check).

HEIC is unsupported. `internal/imghash` already skips it. Do not add a HEIC decoder here.

## API

`FileService.ReadPreview(path string) (domain.Preview, error)`

```go
type Preview struct {
    Kind      string `json:"kind"` // image | text | pdf | none
    MIME      string `json:"mime,omitempty"`
    Text      string `json:"text,omitempty"`
    Data      []byte `json:"data,omitempty"` // image or pdf bytes; empty for text and none
    Message   string `json:"message,omitempty"`
}
```

- Local regular files only. Directory, remote, archive, trash: return `kind: none` and a message. Do not return an error for "unsupported" — the panel shows `Message`. Return an error only when a local file should have been readable and was not (permissions). The panel shows that error.
- Sniff and size check before reading the whole file. Use `os.Stat` then a limited read.
- Image and PDF `Data` is the file bytes, not a re-encode.
- No writes. No temp file.

Regenerate Wails bindings. Do not commit `frontend/bindings/**`.

## Frontend

- Zustand flag `open` only. The path is the active pane's focused row, derived during render. Do not copy it into the store with `useEffect`.
- TanStack Query key `['preview', path]`, `enabled` when the panel is open, path is a local file, and the row is not a directory. `ReadPreview` is a query, not a mutation.
- Blob URL: create it from `Data` for image and pdf. `URL.revokeObjectURL` when the path or kind changes. A `useEffect` whose only job is to revoke the object URL is OK (it is an external handle). Do not use an effect to copy preview data into React state.
- Components under `frontend/src/widgets/quick-view/`. Each file about 100–150 lines. Suggested split: panel shell, body (switch on kind), `styles.ts`. MUI path imports.
- `data-testid`: `panel-quick-view`, `quick-view-image`, `quick-view-text`, `quick-view-pdf`, `quick-view-message`.

Keyboard focus stays on the grid. Arrow keys keep moving the selection; the query key changes with the focused path, so the preview follows. Do not trap focus in the panel.

## Tests

`go test` for the classifier and `ReadPreview` (table):

- small png → image, non-empty data, mime `image/png`
- utf-8 txt → text, body matches, data empty
- file with a NUL in the first 8KB → none
- pdf extension → pdf (a tiny file starting with `%PDF-` is enough)
- file larger than the cap → none, and the test's file is not fully slurped (assert via a reader limit, or a file just over the cap with a counting reader if you inject one)
- directory, `ssh://…`, `trash://…` → none, nil error
- `.heic` → none

No Playwright pixel check. Optional e2e: toggle `btn-quick-view` and expect `panel-quick-view` only if a fixture file is already how other specs set the pane. Skip e2e if that harness cannot point at a local png.

## Check

In the running app: F3 opens the panel; a png, a txt, and a pdf each show; a folder shows the empty message; F3 again closes it; F4 still opens the editor and does not leave the panel in front of it. Confirm the PDF iframe actually paints on darwin. If it does not, ship the Open button and write that in the PR — do not add a JS PDF library.

## Must not

- Open `EditorWorkspace` from this shortcut.
- Preview remote files by downloading them.
- Write the previewed file, including "save a copy".
- `useEffect` to sync the focused path into state.

## Done when

F3 toggles a local preview for png, txt, and pdf; unsupported paths show a message; the editor shortcut is unchanged; Go tests above pass.
