# Spec: Duplicate finder V1 (exact content)

Status: draft-2 (after remote contradiction pass)
Out of scope: OCR, pHash, name-fuzzy pairing, cross-protocol groups, archive internals, Drive/iCloud APIs, multi-job queue, preview of remote images

## Goal

User pick one folder. App find files w/ identical SHA-256 content, review groups, delete extras. Job run background, reopen from status bar.

One root only. Local OS path, or one `ssh://` / `smb://` / `mega://` session path. iCloud Drive and Google Drive entries in connections menu = local folders — treat as local.

## Why remotes not "free"

No hash/stream method on `remoteBackend`. `ReadTextFile` rejects binaries and >5 MiB, loads string — forbidden for this feature.

V1 adds read APIs. Does not reuse content search (`StartSearch` already refuses remote content).

| Backend | How V1 hashes                                                                                                                                                        |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local   | `os.Open` → `io.Copy` into sha256. No full-file buffer.                                                                                                              |
| SSH     | New `OpenRead` on SSH backend (`sftp.Open`). Stream into sha256. No temp file.                                                                                   |
| SMB     | New `OpenRead` on SMB backend (`smb2.Share.Open`). Same.                                                                                                             |
| MEGA    | Existing `DownloadFile` to temp file under config dir (`dup-cache/`). Hash w/ `os.Open`. Delete temp in `defer`. Never `os.ReadFile` whole blob into memory. |

MEGA setup dialog must show: "Files will be downloaded to a temp cache once, then hashed. Need about {byteCount} free disk in the config dir."

Temp disk insufficient mid-scan: non-fatal skip that file, keep going, list under Skipped.

## Entry

- File menu + context menu: "Find duplicates…"
- Disabled when duplicates job already running.
- Disabled when focused path = **local** archive (`FileService.IsArchivePath`). Remotes: never disable for "archive"; remote `.zip` = normal file.

## Setup (state: setup)

- Root: focused pane cwd. Editable.
- Include hidden: default off.
- Min size: default 0.
- Algorithm: read-only "SHA-256 (exact content)". OCR checkbox visible, disabled, hint "V2".
- Estimate button/auto: `EstimateDuplicateScan(root, includeHidden, minSize)` → `{fileCount, byteCount, etaSeconds, protocol, megaDownload: bool}`.

Validation (sync error, don't start):

- empty root
- `ListDir(root, includeHidden)` fails (covers "not a directory", disconnected session, missing path). Don't use `Exists` as directory check.
- local archive root (`IsArchivePath`)
- another dup job running
- empty jobID on start

Estimate walk (names + sizes only, no hashing):

- Must **not** call `walkRemote` as-is (2000 cap, depth 8, swallowed list errors).
- New walker: no 2000/depth cap for V1. Permission/`ListDir` fail on one child → skip that subtree, count as skipped. Session/auth/`not connected` → fail estimate.
- Skip dirs. Don't special-case GFM trash on remotes (trash only under local config dir; skip that path local scans only).
- `etaSeconds` = `byteCount / bytesPerSec[protocol]`. Heuristic, not `DiskUsage` (rejected on remotes).
  - local: 200 MiB/s
  - smb: 30 MiB/s
  - ssh: 10 MiB/s
  - mega: 4 MiB/s (download-bound)
- Show file count, byte count, ETA, MEGA disk warning when `protocol == mega`.

Start disabled til estimate succeeds.

## Running

`NewJobID` then `StartDuplicateScan(jobID, root, includeHidden, minSize)`.

Returns immediately after same validation as estimate. Work in goroutine. `CancelJob` stops walk + hash + MEGA download.

Events:

- `dup:progress` `{jobId, doneFiles, totalFiles, doneBytes, totalBytes, groups, skipped, currentPath}`
- `dup:group` `{jobId, group}`
- `dup:error` `{jobId, path, message, fatal}`
- `dup:done` `{jobId, error?}`

Walk + hash rules:

- Same new walker as estimate (don't reuse `walkRemote`).
- Size-bucket first. Hash only buckets w/ 2+ files.
- Hash via table above. No `ReadTextFile`.
- Skip (non-fatal): can't open, MEGA temp full, permission. Record path + reason.
- Fatal: session dropped, root vanished, job cancelled. Emit `dup:error` `fatal: true` then `dup:done`.
- Don't swallow `ListDir` errors like `walkRemote` does.
- Group key = hex SHA-256. All members share one root → share one protocol. No `local://` scheme — protocol `local` if path has no `ssh://`/`smb://`/`mega://` prefix, else parse from virtual path (`SessionKey()` / scheme). Don't add `protocol` onto `FileEntry`.

Dialog may close. Job keeps running. Status bar chip "Duplicates: {done}/{total}" reopens same job state.

## Error (fatal)

- Restart: cancel if needed, new job, same setup values.
- Discard scan: cancel, drop results. No deletes happened.

Non-fatal skips stay on "Skipped (N)" list inside running + review. No per-file Continue button (continue implicit).

## Review

- Groups: count, size, hash prefix.
- Row: name, path, size, mtime, protocol (`local|ssh|smb|mega`).
- Default: keep = first path sorted; others checked for delete.
- Preview V1:
  - local: existing Open / Open-with
  - remote text: "Open in editor" (`ReadTextFile`) — optional, not required for done
  - remote photos/binaries: no preview (Open and editor both blocked)
- Empty: "No exact duplicates." Close.
- Footer: Delete N files + Merge + Back (discards results, no delete).

## Merge

Confirm:

- N files, M bytes
- `protocol == local` (incl iCloud/GDrive folders): "Undo available for 24h in app trash."
- `ssh` / `smb`: "Permanent delete. App Undo will not restore these."
- `mega`: "Moved to MEGA trash. Restore from MEGA, not from this app."

`FileService.Delete(paths)` once. Don't mix local + remote in one batch (Delete already rejects that). One root ⇒ one protocol, so one call enough.

Done:

- `batchID !== ""` → Undo via `RestoreDeleted`
- else if mega → MEGA-trash copy, no Undo button
- else → no Undo button

Invalidate dir queries for parent dirs. Clear job + chip.

## Backend contract

EstimateDuplicateScan(root string, includeHidden bool, minSize int64) (ScanEstimate, error)
StartDuplicateScan(jobID, root string, includeHidden bool, minSize int64) error

New (not Wails-bound; used by FileService):

- `remoteBackend.OpenRead(path) (io.ReadCloser, error)` on SSH and SMB
- MEGA hash helper: download → hash file → remove temp
- `walkForDuplicates(...)` shared by estimate and scan

`ScanEstimate`: `FileCount, ByteCount, EtaSeconds, Protocol string, MegaDownload bool`
`DuplicateFile`: `Path, Name, Size, ModTime, Protocol string`
`DuplicateGroup`: `Hash, Size, Files []DuplicateFile`

## Must not

- OCR / pHash / fuzzy names
- `ReadTextFile` for hashing
- `os.ReadFile` of MEGA blobs
- Reuse `walkRemote` or content-search remote path
- `DiskUsage` on remotes
- `Exists` as only "is directory" check
- Hand-edit `frontend/bindings/**`
- `mutateAsync`
- Auto-delete
- Two roots / two jobs
- Pretend iCloud/GDrive are `mega://`

- [ ] SSH or SMB unit test: `OpenRead` hashes w/o buffering whole file
- [ ] MEGA unit test or fake: hash path uses temp file + cleanup; `ReadTextFile` not called
- [ ] walker doesn't stop at 2000/depth 8; list error on one child doesn't mark job fatal

## Exclude (V1 patch)

Same control as Find in files → "files to exclude".
Placeholder: `e.g. build, *lock.json, *.md`

- Comma-separated tokens.
- Token rules MUST match existing search exclude (not new glob parser).
- Path skipped if any path segment or file name matches token
  (so `build` drops `build/` dir + everything under it; `*.md` drops markdown files).
- Empty field = exclude nothing.
- Applied in EstimateDuplicateScan AND StartDuplicateScan (same list).
- Skipped-by-exclude files don't count in fileCount / byteCount / ETA.
- Not listed in review Skipped list (that list = errors only).

API (replace 3-arg forms):

EstimateDuplicateScan(root, includeHidden, minSize, exclude string)
StartDuplicateScan(jobID, root, includeHidden, minSize, exclude string)

Must not:

- persist exclude in search prefs
- include-globs in V1 (exclude only)
- change hash / cancel / MEGA temp behavior
